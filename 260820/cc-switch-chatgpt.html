CC Switch + ChatGPT + DeepSeek V4

使用 ChatGPT 桌面软件接入 DeepSeek V4 API

📋 简介

本指南介绍如何使用 CC Switch 工具，将 ChatGPT 桌面软件切换到 DeepSeek V4 API，享受更低成本的 AI 对话体验。

CC Switch 是一个 API 切换工具，可以让 ChatGPT 客户端使用自定义 API 端点。

📥 第一步：准备工作

1.1 获取 DeepSeek API Key

1 访问 DeepSeek 平台 注册账号
2 进入 API Keys 页面 创建密钥
3 复制 API Key（格式：sk-xxxx）
请妥善保管 API Key，不要泄露给他人。

1.2 下载 ChatGPT 桌面软件

1 推荐使用 ChatBox 或 NextChat 等开源客户端
2 下载地址： 
ChatBox: https://chatboxai.app
NextChat: https://github.com/ChatGPTNextWeb/ChatGPT-Next-Web

🔧 第二步：安装 CC Switch

1 下载 CC Switch 工具： 
# GitHub 搜索 CC Switch 或访问
https://github.com/ccswitch/ccswitch
2 安装并运行 CC Switch
3 配置代理端口（默认：7890）

⚙️ 第三步：配置 ChatGPT 软件

3.1 ChatBox 配置

1 打开 ChatBox，进入 设置 → API 提供商
2 选择 自定义 API，填写： 
API 端点: https://api.deepseek.com/v1
API 密钥: sk-xxxx（你的 DeepSeek API Key）
模型: deepseek-chat
3 保存配置，开始对话

3.2 NextChat 配置

1 打开 NextChat，进入 设置
2 在 接口地址 填写： 
https://api.deepseek.com/v1
3 在 API Key 填写你的密钥
4 在 模型 选择： 
deepseek-chat

🚀 第四步：开始使用

1 确保 CC Switch 正在运行（如果需要代理）
2 打开 ChatGPT 客户端，选择 DeepSeek 模型
3 开始对话，享受 DeepSeek V4 的强大能力
DeepSeek V4 的价格比 GPT-4 便宜很多，性能却非常接近。

💡 常见问题

Q: 为什么需要 CC Switch？

A: CC Switch 用于解决网络访问问题，如果你的网络可以直接访问 DeepSeek API，则不需要使用。

Q: 支持哪些模型？

A: DeepSeek 提供以下模型：

deepseek-chat      - DeepSeek V4 对话模型
deepseek-coder     - DeepSeek 代码模型
deepseek-reasoner  - DeepSeek 推理模型

Q: 如何查看 API 用量？

A: 登录 DeepSeek 平台 查看用量和账单。
