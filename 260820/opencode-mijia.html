OpenCode + 小米API 搭建指南

通过 AI 对话控制米家智能家居设备

📋 简介

本指南将帮助你搭建 OpenCode 与 小米米家API 的集成环境，让你可以通过自然语言对话来控制米家智能家居设备。

OpenCode 是一个开源的 AI 编码代理，支持通过 MCP 协议接入各种工具，包括米家设备控制。

🔧 第一步：安装 OpenCode

Windows 安装方式

1 使用 Scoop 安装（推荐） 
scoop install opencode
2 使用 Chocolatey 安装 
choco install opencode
3 使用 NPM 安装 
npm install -g opencode-ai
Windows 用户建议使用 WSL 以获得最佳体验

🔑 第二步：配置 LLM 提供商

1 启动 OpenCode 后，执行 /connect 命令选择提供商
2 或手动设置环境变量： 
# OpenAI
export OPENAI_API_KEY="your-api-key"

# Anthropic Claude
export ANTHROPIC_API_KEY="your-api-key"

# Google Gemini
export GEMINI_API_KEY="your-api-key"

📱 第三步：安装小米API

1 安装 Python 依赖 
# 使用 pip
pip install mijiaAPI

# 或使用 uv
uv add mijiaAPI
2 扫码登录认证 
# 使用 CLI 登录
mijiaAPI login

# 或使用 uvx
uvx mijiaAPI login -p ~/.config/mijia-api/auth.json
使用米家 APP 扫描终端显示的二维码完成登录

🔗 第四步：配置 MCP 集成

1 在项目根目录创建或编辑 opencode.json 配置文件： 
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mijia-api": {
      "type": "local",
      "command": ["uvx", "mijiaAPI", "mcp", "-p", "~/.config/mijia-api/auth.json"],
      "enabled": true
    }
  }
}
Windows 用户需确认 uvx 命令可用（需要安装 uv 工具），路径可能需要使用绝对路径

🚀 第五步：开始使用

1 启动 OpenCode： 
cd /path/to/project
opencode
2 通过自然语言控制米家设备，例如： 
列出我所有的米家设备
把台灯亮度调到 60%
打开客厅空调
查看设备的耗电量统计

🛠️ MCP 工具一览

工具 说明
list_devices 列出所有米家设备
list_homes 列出家庭和房间信息
get_device_spec 获取设备支持的属性和动作
get_device_properties 读取设备属性值
set_device_property 设置设备属性值
run_device_action 执行设备动作
run_scene 执行手动场景
run_speaker_command 通过小爱音箱执行自然语言指令
login 会话内重新登录（凭证过期时使用）
