OpenCode + MiMo 使用指南

OpenCode 接入小米 MiMo 模型完整流程

📋 简介

本指南介绍如何将 OpenCode 与小米 MiMo 模型结合使用，通过 AI 对话辅助编程。

小米 MiMo 是小米推出的高性能 AI 大模型，支持推理和工具调用。

📥 第一步：下载安装 OpenCode

OpenCode 是一个开源的 AI 编码代理，支持在终端中与 AI 对话来辅助编程。有两种使用方式：

1.1 终端使用（CLI）

Windows 安装

1 使用 Scoop 安装（推荐） 
scoop install opencode
2 使用 Chocolatey 安装 
choco install opencode
3 使用 NPM 安装 
npm install -g opencode-ai

macOS / Linux 安装

1 使用官方脚本安装 
curl -fsSL https://opencode.ai/install | bash

验证安装

opencode --version

1.2 下载软件使用（桌面应用）

1 访问 OpenCode 官网 下载桌面版
2 支持 Windows / macOS / Linux 系统
桌面应用提供图形化界面，适合不习惯终端操作的用户。

🔑 第二步：获取 MiMo API Key

1 访问小米 MiMo 平台：https://open.xiaomi.com
2 注册并登录账号
3 进入 API Keys 页面，创建新的密钥
4 复制 API Key（格式：sk-xxxx）
请妥善保管你的 API Key，不要泄露给他人或提交到公开仓库。

⚙️ 第三步：配置 OpenCode 接入 MiMo

方式一：桌面版配置（推荐）

1 打开 OpenCode 桌面版，进入 设置 → Providers（模型提供商）
2 点击 新增自定义 Provider，填写以下信息： 
Provider Name: Xiaomi MiMo
Base URL: https://api.xiaomimimo.com/v1
API Key: sk-xxxx（你的 MiMo API Key）
Model ID: mimo-v2.5-pro
3 关键配置（必填）：开启 Reasoning（思考输出），Reasoning Field 填： 
reasoning_content
MiMo 把思考过程放在 reasoning_content 字段，不配置会丢失思考，工具调用直接失败。
4 保存配置，切换模型为 mimo-v2.5-pro

方式二：终端配置

1 在项目根目录创建或编辑 opencode.json： 
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "xiaomi-mimo": {
      "name": "Xiaomi MiMo",
      "type": "openai",
      "apiKey": "sk-xxxx",
      " baseURL": "https://api.xiaomimimo.com/v1",
      "model": "mimo-v2.5-pro"
    }
  }
}
2 启动 OpenCode 并选择 MiMo 提供商

🚀 第四步：开始使用

终端使用

1 进入项目目录后启动： 
cd /path/to/your/project
opencode
2 在对话框中输入问题，例如： 
帮我分析这个项目的代码结构
解释一下 main.py 文件的功能
帮我修复这个 bug
3 常用快捷键： 
Tab        - 切换 build/plan 模式
/init      - 初始化项目
/undo      - 撤销更改
Ctrl+C     - 退出

桌面版使用

1 打开 OpenCode 桌面应用
2 确认模型已切换为 mimo-v2.5-pro
3 在对话框中输入问题即可
MiMo 模型支持推理和工具调用，适合复杂的编程任务。

💡 常见问题

Q: 为什么工具调用失败？

A: 请确保已配置 Reasoning Field 为 reasoning_content，否则 MiMo 的思考过程会丢失。

Q: MiMo 支持哪些模型？

A: 目前支持 mimo-v2.5-pro，更多模型请查看官方文档。

Q: 如何查看 API 用量？

A: 登录 小米 MiMo 平台 查看用量和账单。
