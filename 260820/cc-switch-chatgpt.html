CC Switch + ChatGPT + DeepSeek V4

使用 CC Switch 将 ChatGPT 客户端接入 DeepSeek V4 API

📋 简介

本指南介绍如何使用 CC Switch 工具，将 ChatGPT 客户端切换到 DeepSeek V4 API，享受更低成本的 AI 对话体验。

CC Switch 是一个 API 切换工具，可以让 ChatGPT 客户端使用自定义 API 端点。

📥 第一步：下载安装软件

需要下载两个软件：CC Switch（代理工具）和 ChatGPT 客户端。有两种使用方式：

1.1 终端使用（CLI）

CC Switch 安装

1 使用 Homebrew 安装（macOS） 
brew install ccswitch
2 使用 Scoop 安装（Windows） 
scoop install ccswitch
3 使用 npm 安装 
npm install -g ccswitch

验证安装

ccswitch --version

启动 CC Switch

# 启动代理服务（默认端口 7890）
ccswitch start

# 查看状态
ccswitch status

1.2 下载软件使用（桌面应用）

CC Switch 桌面版

1 GitHub 下载（推荐） 
https://github.com/ccswitch/ccswitch/releases
选择对应系统版本：
  • Windows: ccswitch-windows-x64.zip
  • macOS: ccswitch-macos-x64.dmg
  • Linux: ccswitch-linux-x64.AppImage

ChatGPT 客户端

1 ChatBox（推荐） 
官网下载: https://chatboxai.app
支持 Windows / macOS / Linux / iOS / Android
2 LobeChat（开源） 
官网下载: https://lobechat.com
GitHub: https://github.com/lobehub/lobe-chat/releases
3 NextChat（开源） 
官网下载: https://nextchat.dev
GitHub: https://github.com/ChatGPTNextWeb/ChatGPT-Next-Web/releases
4 ChatGPT Desktop（开源） 
GitHub: https://github.com/lencx/ChatGPT/releases
桌面应用提供图形化界面，适合不习惯终端操作的用户。

🔑 第二步：获取 DeepSeek API Key

1 访问 DeepSeek 平台
2 注册并登录账号（支持邮箱、手机号、GitHub、Google 登录）
3 进入 API Keys 页面
4 点击 "Create API Key" 创建新密钥
5 复制 API Key（格式：sk-xxxx）
请妥善保管你的 API Key，不要泄露给他人或提交到公开仓库。

⚙️ 第三步：配置 CC Switch 接入 DeepSeek

方式一：桌面版配置（推荐）

1 打开 CC Switch 桌面版，进入 设置 或 API 配置 页面
2 点击 添加新配置，填写以下信息： 
API 名称: DeepSeek V4
Base URL: https://api.deepseek.com/v1
API Key: sk-xxxx（你的 DeepSeek API Key）
Model: deepseek-chat
3 保存配置
4 启用该配置，设置代理端口（默认 7890）

方式二：终端配置

1 创建配置文件 ~/.ccswitch/config.json： 
{
  "proxy": {
    "port": 7890
  },
  "apis": [
    {
      "name": "DeepSeek V4",
      "baseUrl": "https://api.deepseek.com/v1",
      "apiKey": "sk-xxxx",
      "model": "deepseek-chat"
    }
  ]
}
2 启动 CC Switch 并加载配置： 
ccswitch start --config ~/.ccswitch/config.json
3 验证代理是否运行： 
ccswitch status
确保 CC Switch 正在运行，代理端口已开启。

🚀 第四步：在 ChatGPT 客户端中使用

方式一：桌面版使用

ChatBox 配置

1 打开 ChatBox，进入 设置
2 在 API 提供商 中选择 自定义 API
3 填写配置： 
API 端点: https://api.deepseek.com/v1
API 密钥: sk-xxxx（你的 DeepSeek API Key）
模型: deepseek-chat
4 保存配置，开始对话

NextChat 配置

1 打开 NextChat，进入 设置
2 在 接口地址 填写： 
https://api.deepseek.com/v1
3 在 API Key 填写你的密钥
4 在 模型 选择： 
deepseek-chat
5 保存配置，开始对话

方式二：终端使用

1 确保 CC Switch 正在运行： 
ccswitch status
2 使用 curl 测试 API： 
curl -x http://localhost:7890 https://api.deepseek.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-xxxx" \
  -d '{
    "model": "deepseek-chat",
    "messages": [
      {"role": "user", "content": "你好"}
    ]
  }'
3 或使用 Python 调用： 
import openai

client = openai.OpenAI(
    api_key="sk-xxxx",
    base_url="https://api.deepseek.com/v1"
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "你好"}
    ]
)

print(response.choices[0].message.content)
DeepSeek V4 支持长上下文、代码生成、推理等多种能力。

💡 常见问题

Q: 为什么需要 CC Switch？

A: CC Switch 用于解决网络访问问题，如果你的网络可以直接访问 DeepSeek API，则不需要使用。

Q: 支持哪些模型？

A: DeepSeek 提供以下模型：

deepseek-chat      - DeepSeek V4 对话模型
deepseek-coder     - DeepSeek 代码模型
deepseek-reasoner  - DeepSeek 推理模型

Q: 如何查看 API 用量？

A: 登录 DeepSeek 平台 查看用量和账单。

Q: 连接失败怎么办？

A: 检查以下几点：

1. CC Switch 是否正在运行
2. API Key 是否正确
3. 网络连接是否正常
4. 代理端口是否正确
