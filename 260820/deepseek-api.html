Codex + DeepSeek 使用指南

OpenCode 配置 DeepSeek-V4 模型完整流程

📋 简介

DeepSeek 是一家专注于 AI 大模型研发的公司，提供高性能的 API 服务。本指南将帮助你快速上手 DeepSeek-V4 模型的 API 调用。

DeepSeek API 兼容 OpenAI API 格式，可以无缝切换。

📥 第一步：下载安装 OpenCode

OpenCode 是一个开源的 AI 编码代理，支持在终端中与 AI 对话来辅助编程。

Windows 安装

1 使用 Scoop 安装（推荐） 
scoop install opencode
2 使用 Chocolatey 安装 
choco install opencode
3 使用 NPM 安装 
npm install -g opencode-ai

macOS / Linux 安装

1 使用官方脚本安装 
curl -fsSL https://opencode.ai/install | bash

验证安装

opencode --version
更多安装方式请参考 OpenCode 官网

🔑 第二步：获取 API Key

1 访问 DeepSeek 平台：https://platform.deepseek.com
2 注册并登录账号
3 进入 API Keys 页面
4 点击 "Create API Key" 创建新的 API Key
请妥善保管你的 API Key，不要泄露给他人或提交到公开仓库。

📦 第三步：安装依赖

Python

# 安装 OpenAI 官方库（DeepSeek 兼容）
pip install openai

# 或使用 uv
uv add openai

Node.js

# 安装 OpenAI 官方库
npm install openai

# 或使用 pnpm
pnpm add openai

🚀 第四步：调用 API

Python 示例

from openai import OpenAI

# 初始化客户端
client = OpenAI(
    api_key="your-deepseek-api-key",
    base_url="https://api.deepseek.com/v1"
)

# 调用 DeepSeek-V4 模型
response = client.chat.completions.create(
    model="deepseek-chat",  # DeepSeek-V4 模型
    messages=[
        {"role": "system", "content": "你是一个有帮助的助手。"},
        {"role": "user", "content": "请介绍一下DeepSeek-V4模型的特点。"}
    ],
    temperature=0.7,
    max_tokens=1000
)

# 输出结果
print(response.choices[0].message.content)

Node.js 示例

import OpenAI from 'openai';

// 初始化客户端
const client = new OpenAI({
    apiKey: 'your-deepseek-api-key',
    baseURL: 'https://api.deepseek.com/v1'
});

// 调用 DeepSeek-V4 模型
async function chat() {
    const response = await client.chat.completions.create({
        model: 'deepseek-chat',  // DeepSeek-V4 模型
        messages: [
            { role: 'system', content: '你是一个有帮助的助手。' },
            { role: 'user', content: '请介绍一下DeepSeek-V4模型的特点。' }
        ],
        temperature: 0.7,
        max_tokens: 1000
    });

    console.log(response.choices[0].message.content);
}

chat();

cURL 示例

curl https://api.deepseek.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer your-deepseek-api-key" \
  -d '{
    "model": "deepseek-chat",
    "messages": [
      {"role": "system", "content": "你是一个有帮助的助手。"},
      {"role": "user", "content": "请介绍一下DeepSeek-V4模型的特点。"}
    ],
    "temperature": 0.7,
    "max_tokens": 1000
  }'

⚙️ 第五步：参数说明

参数 说明 默认值
model 模型名称，DeepSeek-V4 使用 deepseek-chat -
messages 对话消息数组，包含 role 和 content -
temperature 控制输出的随机性，0-2 之间 1.0
max_tokens 最大输出 token 数量 4096
top_p 核采样参数，0-1 之间 1.0
stream 是否使用流式输出 false

💡 第六步：流式输出

流式输出可以实时显示生成内容，提升用户体验。

Python 流式示例

from openai import OpenAI

client = OpenAI(
    api_key="your-deepseek-api-key",
    base_url="https://api.deepseek.com/v1"
)

# 流式调用
stream = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "写一首关于春天的诗"}
    ],
    stream=True
)

# 实时输出
for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
